    CNC Hot-Wire Foam Cutting Machine

    This machine was built as part of the final year Mechanical Engineering project along with 3 other students.

    The project was conceptualized as a requirement of Team Avions, the aeromodelling club of PESIT-BSC to be able to consistently cut prototype foam core wings.

    The machine was designed to be able to cut wings and other objects from foam using a hot current carrying NiChrome wire. The machine was designed from the ground up to fit in the prototyping lab and is still used by Team Avions.
